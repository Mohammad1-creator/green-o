# green-o: نظام إدارة المصنع

نظام عربي بالكامل (من اليمين لليسار) لإدارة مصنع: لوحة إدارة للكمبيوتر، وتطبيق جوال (PWA) للموظفين. يغطي المهام والصيانة والإنتاج والإشعارات والتقارير.

> قيد البناء. المرحلة الحالية: **0 (التأسيس)**.

## الوثائق

- [الخطة المعتمدة](docs/plan.md)
- [سجل القرارات](docs/decisions.md)
- [إعداد البيئات والنشر](docs/deploy.md)

## التقنيات

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · shadcn/ui (Base UI) · Supabase · Vercel

## التشغيل محلياً

المتطلبات: Node.js 24 أو أحدث. ومن المرحلة 1: Docker Desktop.

```bash
npm install
cp .env.example .env.local
npm run dev
```

ثم افتح http://localhost:3000

## الأوامر

| الأمر | ما يفعله |
|---|---|
| `npm run dev` | تشغيل نسخة التطوير |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run check` | الفحص، والأنواع، والتنسيق، واختبارات الوحدات |
| `npm run test:e2e` | الاختبارات الشاملة في المتصفح (أول مرة: `npx playwright install chromium`) |
| `npm run check:secrets` | بعد البناء: يتأكد أن لا مفتاح سري وصل إلى ملفات المتصفح |
| `npm run format` | تنسيق الكود |
| `npm run supabase -- <أمر>` | Supabase CLI بإصدار مثبّت |

## الفروع

- `dev`: التطوير. كل تغيير يُرفع هنا، ويُنشر على بيئة التطوير.
- `main`: الإنتاج. يُدمج فيه بعد اعتماد كل مرحلة.

## قواعد الأمان

- لا مفاتيح سرية في الكود، ولا في أي متغير يبدأ بـ `NEXT_PUBLIC_`.
- الصلاحيات تُفرض في قاعدة البيانات (RLS) وعلى الخادم، وليس بإخفاء الأزرار فقط.
- البيانات التجريبية في بيئة التطوير فقط.
